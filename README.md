Project Overview
This repository showcases three website projects developed as part of the Web Development Activity-Based Learning (ABL) assignment. The projects focus on creating informative and visually appealing webpages using HTML and CSS. Each website is designed for a different purpose, helping to explore various aspects of web design and development.

Projects
1. Restaurant and Cafe Website
This webpage presents a restaurant and cafe with an appealing layout for displaying food items and menu information. It aims to provide visitors with an enjoyable browsing experience through organized content and attractive styling.

2. Bakery and Cake Shop Website
This website showcases a variety of cakes, pastries, and other bakery products. It focuses on presenting product images and details in an attractive layout using suitable colors, fonts, and CSS styling.

3. . Adventure and Trekking Website 
Build a website showcasing trekking routes, camping trips, difficulty levels, trip schedules, equipment checklists, safety guidelines, and package prices. Use image overlays and visually distinct information panels.

Conclusion
This Activity-Based Learning project provided an opportunity to apply HTML and CSS concepts in practical website development. Working on three different webpages helped improve my coding skills, creativity, and understanding of webpage design.
